# v17 功能骨架对齐边界

## 1. 新特征项只带来小幅改善

在相同 17 帧序列和相同 L20 模型上，v17 的掌部归一化语义点 RMSE 从 v16 的 `0.132862` 降到 `0.132809`，骨方向 RMSE 从 `16.812°` 降到 `16.646°`，屈曲角 RMSE 从 `14.119°` 降到 `13.861°`。改善幅度有限，说明问题不只是缺少一个损失项。

## 2. 当前不能要求 MANO 与 CAD 表面完全重合

MANO 表面保留自然人手比例，L20 link 表面由机械装配决定。v17 对齐的是掌部归一化的功能骨架和任务关系；绝对 CAD 点和表面重合仍是诊断项，不能用来替代功能指标。

## 3. 仍需目标条件化骨架适配

如果后续验收要求进一步减小指根位置和指骨方向差异，需要先调整 `K_R` 的目标条件化骨长/局部坐标与语义点规则，再运行新的版本。当前结果不能声称 R 与 L20 已完全对齐。
