# v17：R 与 L20 功能骨架对齐

本版本在 v16 的功能特征和 q 平滑基础上，增加了所有非腕部语义点的掌部归一化位置，以及每根手指相邻骨段之间的屈曲角。自然 MANO 表面仍保持独立；L20 使用 URDF 的 16 个独立 `q`、限位和 5 条 mimic。

## 运行结果

17 帧固定合成序列上，17/17 帧求解成功，限位违规为 0，mimic 残差为 0。v17 相对于同一序列的 v16 解：

| 指标 | v16 | v17 |
|---|---:|---:|
| 掌部归一化语义点 RMSE | 0.132862 | 0.132809 |
| 骨方向 RMSE | 16.812° | 16.646° |
| 屈曲角 RMSE | 14.119° | 13.861° |

改进目前是小幅的，说明新增的语义点/屈曲角项已经进入目标函数，但 L20 的机械拓扑与自然 MANO 仍存在不可完全消除的差异。v17 不能声称两个表面已经完全对齐。

## 可视化

ASCII MuJoCo 结果位于 `experiment/v17_R_L20_alignment_viewer/`：

- `v17_overlay_contact_sheet.png`：蓝色自然 MANO-R 与灰色 L20 放在同一坐标系中叠加；
- `v17_separate_contact_sheet.png`：蓝色 R 与灰色 L20 分开放置，便于分别观察手形和机械动作；
- `frame_000/008/016_*.png`：张开、拇食指捏合、拇中指对指三个关键帧。

分开放置的平移只用于显示，不改变 q、特征目标或运动学模型。

## 边界

序列仍是固定 MANO 姿态插值，不是摄像头输入。碰撞/接触和执行器 `u` 未加入。后续若要进一步减少手形差异，应调整目标条件化功能骨架或语义点定义，而不是把自然 MANO 表面强行拟合到 CAD 外壳。
