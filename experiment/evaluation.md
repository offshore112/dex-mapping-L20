# 统一测评规则

**状态：测评方案草案，尚未执行。**实际数据、关键点对应、阈值、硬件与样本量待 M0–M2 决定。首次正式比较前冻结这些配置并写明版本，之后改口径需要新版本与重测。

## 1. 每次测评的输入

输入必须包括：方法/代码版本、权重、运行配置、随机种子、输入来源（干净标注或视觉预测）、目标机器人与驱动描述、固定测试 ID 名单、关键点对应、坐标/单位、阈值及测评规则版本。

按四种条件分别测：见过人+见过机器人；未见人+见过机器人；见过人+未见机器人；未见人+未见机器人。未覆盖的条件写“未测”，不扩大结论。

调试 smoke 样本只验证接口，不作为泛化测试集。正式划分见 `dataset.md`。禁止测试集调权重、挑动作、生成额外适配标签或微调后仍称 zero-shot。

## 2. 指标定义与冻结项

| 指标 | 草案定义 | 正式运行前要固定 |
|---|---|---|
| 任务特征误差 | 目标与实际 FK 产生的对应指尖/向量误差 | 关键点对应、腕部坐标、对齐方式、缺失掩码 |
| 归一化指尖误差 | 每个有效对应指尖的欧氏距离除以预定义掌部尺度后取平均 | 尺度定义、每帧/每序列聚合规则 |
| 绝对距离误差 | 同一米制坐标下距离，输出时可换算毫米 | 不允许为了误差低而逐帧重新对齐/缩放 |
| 方向误差 | 对应非零指骨/任务向量的夹角，单位度 | 零长度处理、向量集合 |
| 捏合指标 | 比较预测与固定参考捏合关系的 precision/recall/F1 | 距离阈值、指尖对、阈值来源、零分母规则 |
| 限位违规率 | 存在任意有效关节/执行器越限的样本数 ÷ 有效样本数 | 数值容差、限位来源，投影前后分别报告 |
| 耦合残差 | 相对于 ψ(u;E) 或真实回读的关节关系误差 | 真实/简化模型、关节单位与聚合方式 |
| 平滑与响应 | 关节/执行器速度变化，以及动作切换延迟 | 采样频率、过滤配置、时间对齐 |
| 推理时延 | 单阶段与端到端的 p50/p95 | 硬件、批大小、预热、计时同步、样本数 |
| 配置成本 | 实际人工对应、标定动作数、配置时间、测试时优化成本 | 哪些步骤计入、计时范围 |

有物体时再增加：接触 F1、穿透和真实任务成功率。没有物体/接触真值就写“未测”，不要把空中指尖靠近视为实际接触成功。

第一阶段用目标虚拟手的参考特征；第二阶段和组合模型用机器人可实现的目标及任务约束。精确坐标不可达时，报告不可达比例与最优参考残差，不随方法不同改变目标。

## 3. 公平比较与诊断参照

必须有简单归一化/角度方法、已有优化基线、直接映射模型和完整两阶段模型。按数据与输入可用性明确哪些对照适用。

消融：去掉源/目标尺寸条件，去掉驱动约束，去掉/打乱机构描述，去掉中间表示或直接映射。每项都在固定测试名单上做。

诊断参照可以使用干净标注输入、每目标优化参考或额外信息帮助定位误差。写清使用了哪些信息；局部求解结果不是自动成立的理论上界。

## 4. 聚合、分组与失败

- 同时报告全体与按操作者、尺寸、机器人、动作分组的结果，报告最差组及有效样本量。
- 固定无效输入的处理策略，报告检测失败/求解失败/不可达比例，不能只统计成功帧。
- 学习方法按实际独立运行报告种子与波动；统计区间以人/序列等适当独立单位计算。
- 首次正式测评时固定 5–10 个诊断样例 ID，跨版本保持；另加每版新发现的失败，不替换固定名单。
- 违规输出仅用于离线诊断；正式可执行结果采用一致约束策略，报告策略成本。

## 5. 每版输出

`experiment/<版本名>/metrics.json`：真实数值、单位、定义版本、分组、样本量、失败比例与运行配置链接。

`figures/`：目标/实际关键点叠图、按尺寸与机构分组图、误差或响应随时间图。结果不好也保留图。

`failure_cases.md`：固定诊断样例、现象、可复核证据、原因假设和下一步。未经验证的原因标为假设。

完成后追加 `results.md`，更新 `handoff.md`。
