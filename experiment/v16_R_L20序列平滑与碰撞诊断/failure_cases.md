# v16 失败边界

## 1. 时间平滑与任务误差的权衡

在同一条 17 帧合成序列上，加入 `smooth_weight=0.50` 后最大独立 q 单步变化由 `0.866059 rad` 降到 `0.434351 rad`，平均单步变化由 `0.262775 rad` 降到 `0.197362 rad`。相应的平均骨方向 RMSE 从 `16.563°` 变为 `16.812°`，说明平滑项会牺牲少量静态特征误差。这个对照只说明当前优化器的权衡，不代表真实控制平滑或延迟。

## 2. 碰撞网格不可直接使用

对 v16 的 17 帧 q 序列执行 MuJoCo 原始接触诊断，最大原始接触数为 39；即使过滤直接父子 link，最大非相邻接触数仍为 26，且所有帧都有非相邻接触。当前结果更可能包含 URDF/CAD 网格装配重叠或碰撞网格未清理，不能直接作为自碰撞损失或接触成功标签。

因此 v16 没有把碰撞项加入 q 优化，也没有把这些接触数解释为失败抓取。下一步要先建立 link 对过滤、碰撞网格清理、指腹接触点和接触法向规则，再加入约束优化。

## 3. 合成序列边界

序列由三个固定 MANO 姿态向量线性插值得到，不是摄像头序列，也没有操作者/序列划分，不能用于泛化结论。
