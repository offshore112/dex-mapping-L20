# v23 动作质量复核：未通过用户验收

日期：2026-10-23（Asia/Shanghai）。用户反馈：“做的动作非常不自然，不是我想要的结果，弯曲的时候手指网格也有点问题”，并询问这种虚拟手 R 能否映射到 L20。

**当前判断：工程链路通过，动作质量未通过用户验收；不能将当前序列视为可靠的 L20 控制上游。** 原数值记录和回放结果保留，原先的“passed”仅覆盖文件接口、重复性、显示顶点和程序退出。它不证明自然性、本人动作忠实度或机器人可执行性。

## 已核查的证据

- `fit_mediapipe_to_mano_v21.py` 给 15 个局部 MANO 关节各 3 个轴角分量，只用统一 tanh 分量范围、姿态幅值惩罚和相邻帧平滑；没有逐关节的屈伸轴、外展/扭转约束，也没有碰撞约束。轴角分量被限制不等于满足人体关节活动限制。
- v23 只修正小拇指 DIP，没有修正其他关节。对当前 774 帧补充只读分解：食指/中指/无名指 DIP 轴向扭转绝对值峰值分别约 **64.69° / 62.17° / 72.81°**；PIP 也存在轴向旋转。完整描述值见 [review.json](review.json)。这些角度相对源形态的 MANO 中性轴，不是独立测得的解剖角度，不用作已冻结的人体限位或通过阈值。
- 并排动画的金色手和蓝色 R 都来自同一套拟合姿态；二者动作相似不能验证与真实手动作相同。截图中的弯曲表面有明显不自然的局部变形，但塌陷、扭转、穿插各自的贡献尚未完成专门网格/碰撞检测，不能把它们统称为已定位的单一渲染错误。
- 原采集脚本保存图像坐标关键点、世界关键点、手性和时间戳，没有保存同步 RGB 视频；当前 experiment/DataSet 搜索也未找到对应视频。因此缺少真实动作的逐帧视频对照，检测误差与逆运动学拟合误差尚不能完全分离。
- v22/v23 采用 `theta_R = theta_i`，源姿态误差会被传递到 R；源/R 骨方向 RMSE 小只说明迁移接近该源拟合，不说明源拟合正确。
- 当前固定 beta_R=0 的自然 MANO 表面是 v12 候选，不能称为已经与 L20 运动学等价的最终目标几何。v18 有单独的 L20 条件化功能骨架适配，但这不使 MANO 表面自动满足机器人限位或耦合。

## “能映射到 L20”需要区分什么

| 层级 | 当前证据与判断 |
|---|---|
| 网格显示 | MANO 顶点可正常回放；自然性/局部变形未通过用户验收。显示一致性不验证人体姿态正确。 |
| R→L20 q | 已有功能特征、目标条件化骨架与 URDF 有界优化接口，支持离线算法试验；当前 v23 的 774 帧未进行 L20 q 求解。历史 17 帧合成和 48 帧旧真实接口结果不能代替本序列的任务验证。 |
| q→真实执行器 u | SDK 槽位、零点、方向、实际耦合和硬件回读仍未完成验证；不能宣称当前 R 已能准确控制用户 L20。 |

现有 q 优化使用骨方向、指尖关系和关节约束，没有把整个 MANO 皮肤网格作为机器人运动学状态。因此，单纯表面变形不一定破坏骨架驱动；但如果骨架动作/指尖也错误，求解器可能只是在追随错误目标。项目指尖还是取自网格顶点，不能假设皮肤问题与全部任务点完全无关。

## 后续方案（计划，未运行）

1. 用同步真实视频、检测骨架、拟合骨架、虚拟手网格四者对照，先验证张开、单指弯曲、握拳和捏合的逐帧动作。新记录的动作/序列需登记，不能作为独立泛化成绩用于调参。
2. 在人体局部坐标下限制不必要的 IP 扭转/侧弯；四指近端指间/远端指间关节以屈伸为主的参数化可作为待比较候选，拇指单独处理。不能继续把 45 个分量的统一范围当作解剖约束，也不能只把所有旋转一概归零。
3. 保留两阶段研究问题：第一阶段处理人体尺寸并输出动作可信、语义明确的目标 R；目标几何由 L20 辅助建模/条件化模块确定。第二阶段处理 L20 实际驱动、耦合和限位。R 的功能骨架/指尖特征与可视化表面分开验证，不能用漂亮外观替代运动学验证。
4. 源动作验收通过后，再在固定诊断动作名单运行 R→L20 q 对照，检查任务点、限位、耦合、时间跳变和失败帧；实际 u/硬件另行核查。本轮没有新增求解或真机运行。

MANO 本身包含姿态相关形变和蒙皮，它是人手表面模型；异常姿态输入不能靠表面模型自动转成可靠的机器人运动。依据：[MANO 官方说明](https://mano.is.tue.mpg.de/)、[smplx 作者实现](https://github.com/vchoutas/smplx/blob/main/smplx/lbs.py)。本项目的功能骨架解耦依据 `scripts/run_r_l20_feature_baseline_v15.py`、`scripts/build_target_conditioned_sequence_v18.py` 和 `scripts/shared_r_l20.py`。
