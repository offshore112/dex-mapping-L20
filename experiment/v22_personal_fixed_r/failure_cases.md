# v22 诊断与适用边界

本次未发生 Python/MuJoCo 崩溃。以下是当前方法仍需检查的行为，不代表已解决。

1. **指尖关系改变。** 同一组局部姿态作用到不同形态时，指尖关系并不完全相同。源手最接近拇食指帧为 190：源归一化距离 0.170207，R 为 0.191057；源最接近拇中指帧为 383：源距离 0.227581，R 为 0.184289。这里为关节点/表面顶点代理距离，不是表面接触真值；本版没有捏合约束。
2. **源序列抖动仍可能传入。** 774 帧中局部姿态轴角参数分量最大单步变化 0.443704 rad。直接迁移不额外滤波，源序列的姿态变化被保留，尚未验证实时响应。
3. **没有腕部自由运动。** 本版固定腕部锚点，以检查手指动作及形态差异。原 MediaPipe 坐标和掌面坐标的转换不能直接用作真实相机外参。
4. **目标 R 仍为候选。** 采用已有 v12 beta_R=0 自然人手形态与固定目标尺度，未证明其能覆盖所有 L20 功能任务；本版不更改 L20 拓扑、联动或独立执行器定义。
5. **显示与物理分开。** MuJoCo 仅显示 skin，碰撞/接触与执行器 u 未测；不能从动画得出真机可执行结论。
6. **下游接口约定。** v22 使用独立腕部锚定，旧 v20 必须保留 `target_landmarks_m`，而不是直接用 beta/theta 重新前向。本次透传一致性已验证。

固定诊断帧由本次全输入序列的规则选取：首帧、时间序列中间索引帧、末帧、源手拇食指最近帧和源手拇中指最近帧，实际 ID 为 0、190、383、387、773。后续方法比较应沿用该名单，不因结果好坏更换；动画总览可能显示其最近的采样预览帧并标注实际 ID。
