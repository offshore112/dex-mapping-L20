# v14 失败与边界记录

## full-landmark-pinching

- **输入：**v13 R 的三个合成目标：平展、拇食指捏合、拇中指对指。
- **现象：**将 21 个 R 语义点同时作为目标时，拇食指目标距离约 0.46 mm，但 L20 解的实际距离约 63.88 mm；拇中指目标距离约 0.80 mm，实际约 55.84 mm。全点 RMSE 分别为 26.61 mm 和 27.07 mm。
- **判断：**这表明 v13 R 的绝对关键点坐标与当前 L20 机械代理点不一致；不能据此宣称 R→L20 映射已经支持捏合/对指。

## task-only-pair-diagnostic

- **现象：**只优化相关拇指/手指的 7 个独立 q、冻结其他手指在零位时，FK 点模型可以把拇食指和拇中指的指尖距离压到接近 0 mm，限位和 mimic 残差为 0。
- **边界：**这是无碰撞、无接触法向、无执行器 `u` 的点距离诊断；指尖“相交”不等于真实捏合成功。需要后续加入指尖方向、接触间隙、碰撞和驱动约束。
