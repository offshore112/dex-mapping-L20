# v1_MANO环境与加载核查

日期：2026-10-14（Asia/Shanghai）。类型：环境/模型接口核查，属于调试验证；不用于证明映射精度或泛化。

## 本次改什么、为什么

用户提供本地 MANO_LEFT.pkl 与 L20 左手目录，随后明确要求创建单独的 Conda 环境下载依赖。本次在项目 `.conda/envs/mano-l20` 创建 Python 3.11 环境，安装 CPU PyTorch、smplx 与几何/可视化依赖，运行真实 MANO 前向并导出中性形状。

输入路径见 [配置](../../environment/mano_l20_paths.json)。原始文件只读；兼容读取旧 Chumpy 的存储数组，不改源文件、不执行任意 Chumpy 计算图。

## 固定检查项

1. 原始文件哈希、数组形状、有限性、蒙皮权重与面索引范围。
2. 左手；β=0；45 维局部轴角=0；整体旋转/平移=0；平直平均姿态配置。
3. 中性前向顶点与模板一致；原生 16 个关节与关节回归器一致；最大绝对误差阈值均为 1e-9 模型单位。这是双精度数值一致性容差，不是几何拟合验收阈值。
4. 形状参数梯度有限且非零；一个指定姿态参数扰动后顶点产生有限、非零变化。扰动不解释为真实抓取动作或机器人指令。
5. 固定输出 21 点顺序：腕、拇、食、中、无名、小，每指 3 个原生关节+1 个选定网格指尖。指尖顶点采用作者 smplx 的索引规则并记录来源。
6. L20 URDF 与所有被引用网格存在，保存哈希；本次资源检查不等于 FK、尺度或真实控制已验证。

## 输出与边界

`environment_check.json`、`landmarks_mano21.json`、`mano_reference.npz`、`mano_neutral.obj`、`mano_left_neutral.png`。

坐标采用模型的米制约定，尚未通过实物标定核对；输出保持 MANO 原始轴。图片只为观察使用 PCA 显示轴，不改变数据坐标。未进行 L20 几何拟合、网络训练、泛化测评或真机测试。

每次新运行必须使用新输出目录；脚本发现已有成功报告会拒绝覆盖。
