# v18：L20 目标条件化功能骨架适配

v17 直接比较自然 MANO 功能骨架与 L20 机械骨架时，仍然存在人体比例和机械比例不一致的问题。v18 固定建立一个目标条件化适配器：以 L20 零位的掌部框架、骨长和基准方向建立 `K_R^L20`，再把 MANO 相对动作方向迁移到这套 L20 比例的骨架上。

自然 MANO 表面 `S_R` 没有被修改，也没有把每一帧的绝对 MANO 点重新拟合到 L20。捏合和对指的任务指尖关系仍使用原始 R 任务目标，避免为了适配 L20 形状而破坏任务。

## 运行结果

17 帧固定合成序列上：

- 17/17 帧求解成功；限位违规 `0`；mimic 残差 `0`；
- L20 条件化骨架目标下，掌部归一化语义点 RMSE `0.108737`；
- 屈曲角 RMSE `6.728°`；
- 原始 R 任务对误差：拇食指平均归一化距离误差 `0.001434`，拇中指 `0.001120`；
- 最大 q 单步变化 `0.979151 rad`，说明任务约束与目标骨架形状之间仍有时间平滑权衡。

v18 的形状误差不能直接与 v16/v17 的数值做同一目标比较，因为 v18 已经把形状目标替换为固定的 L20 条件化骨架。完整对照见 `alignment_sequence/comparison.json`。

## 文件

- `adapted_sequence_v18.json`：固定 L20 目标条件化骨架目标；包含原始 R 任务目标和适配后的形状目标；
- `alignment_sequence/metrics.json`：逐帧 q、形状对齐和原始任务对指标；
- `alignment_sequence/sequence_q.json`：16 个独立 q 及 5 条 mimic 展开结果；
- `alignment_sequence/comparison.json`：v16/v17/v18 对照及目标定义说明；
- `v18_R_L20_alignment_viewer/`：叠加视图和分开放置视图。

## 当前边界

目标条件化适配已经建立并运行，但还不是最终网络。当前适配使用 L20 零位作为仿真参考，不是真机标定；碰撞/接触、摄像头输入、执行器 `u` 和跨操作者泛化仍未运行。
