# v19：目标条件化骨架的整段轨迹联合优化

v19 使用 v18 的 L20 目标条件化骨架目标和原始 R 任务指尖关系，但把 17 帧的 16 个独立 `q` 一起优化，而不是逐帧贪心求解。目标函数同时包含条件化骨架、原始拇食指/拇中指任务关系和相邻 q 平滑项。

## 运行结果

连续优化的续跑版本位于 `global_trajectory_continuation/`：

- 全局求解器收敛：`True`；17 帧全部有效；限位违规 `0`；mimic 残差 `0`；
- 最大 q 单步变化从 v18 的 `0.979151 rad` 降到 `0.830350 rad`；平均单步变化从 `0.243899` 降到 `0.228392 rad`；
- 条件化语义点 RMSE `0.109628`，屈曲角 RMSE `6.833°`；
- 原始 R 任务对平均归一化距离误差：拇食指 `0.001489`，拇中指 `0.001109`。

第一次从 v18 初值启动、迭代上限为 35 的运行没有达到收敛条件，保留在 `global_trajectory/` 作为失败/未收敛对照；续跑使用该结果继续优化后收敛。

## 边界

这是离线全局 q 优化，不是在线控制器。碰撞/接触、执行器 `u`、摄像头输入和真实硬件仍未加入；条件化形状指标相对 v18 的新目标计算，不能解释为自然 MANO 表面完全重合。
