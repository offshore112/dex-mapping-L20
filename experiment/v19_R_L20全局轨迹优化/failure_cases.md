# v19 全局轨迹优化边界

## 1. 首次运行未收敛

使用 v18 序列 q 作为初值、smooth_weight=`0.80`、max_nfev=`35` 的第一次全局运行达到迭代上限，求解器 `success=false`，最大 q 单步变化为 `0.829947 rad`。该目录保留为未收敛对照，不作为 v19 正式结果。

## 2. 续跑后收敛但任务误差有小幅权衡

使用第一次全局结果作为初值继续优化后，求解器收敛，最大 q 单步变化为 `0.830350 rad`。相对 v18，条件化语义点误差略增，拇食指任务对误差也略增；这说明整段平滑与任务保持之间存在权衡。

## 3. 碰撞和执行器边界未解决

全局优化仍没有加入当前不可靠的 URDF 碰撞几何，也没有真实执行器 `u` 或控制延迟。因此 q 轨迹连续不等于真机动作安全或可执行。
