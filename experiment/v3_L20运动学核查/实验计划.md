# v3_L20运动学核查

日期：2026-10-16（Asia/Shanghai）。当前为执行前计划，实际结果另存 metrics.json。

## 改什么、为什么

用户询问怎样检查 L20 正运动学、坐标和联动。本次增加可复用的 URDF FK 读取器、固定诊断名单、独立库复核与离线可交互预览。先验证模型计算，再进行后续腕部/指尖定义与 R 几何拟合。

原始 MANO、URDF 和网格保持只读；输入路径来自 environment/mano_l20_paths.json。仅使用左手，根坐标为 hand_base_link，计算采用米与弧度，报告和显示可转换为毫米/角度。关节按名称映射，不假设 SDK 或数组序号等价。

## 冻结诊断样例与规则

配置见 [config.json](config.json)。样例固定为：零姿态 1 个；16 个独立关节各自 +0.1 rad 1 个；每个独立关节上下界各 1 个，共 32 个；种子 20261016 的 40 个限位内随机姿态；5 组 mimic 主关节各取 5 个范围比例，共 25 个。预计 114 个模型配置。这些不是训练/正式泛化样本。

检查：

1. 22 link/21 revolute/5 mimic/16 独立坐标，唯一根、树结构、轴为单位向量、引用资源存在；固定 rpy 不丢失。
2. `T_child = T_parent @ T_origin(xyz,rpy) @ Rot(axis,q)`；URDF rpy 使用 `Rz(yaw) @ Ry(pitch) @ Rx(roll)`。确认旋转矩阵正交、行列式为 1、齐次矩阵末行为 [0,0,0,1]。
3. 与独立 yourdfpy 读取器比较 114 个姿态的每个 link 位姿；只传入独立关节，让对方自行处理 mimic。位置容差 1e-10 m、姿态容差 1e-9 rad，仅用于双精度模型计算一致性。
4. 单关节变化只影响自己的子树；当前关节原点不因绕自身轴旋转而移动；局部探针的有限差分速度与世界轴叉积方向一致。探针不是指尖或接触点。
5. 每个姿态展开全部 mimic，检查位置限位与联动公式；拒绝未知关节、独立给从动关节下角度、独立关节越限。
6. 核对四指 MCP_pitch→PIP、PIP→DIP 关节中心距在姿态变化下保持；统计完整网格的模型范围。物理尺度与真机结构另待外部验证，不由量级推断为已标定。
7. 生成零姿态/食指 PIP=0.5 rad 图和离线 HTML 滑杆检查器；预览显示抽样三角面，不用于碰撞和接触判断。浏览器 FK 与 Python 固定样例另行比较。
