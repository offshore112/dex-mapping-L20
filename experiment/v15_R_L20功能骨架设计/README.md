# v15：R_L20 功能骨架与自然表面设计

## 为什么需要 v15

v14 说明了两个事实：

1. 把 v13 R 的 21 个绝对点直接作为 L20 的 21 个绝对点目标时，拇食指/拇中指对指不能保持 R 的目标距离；
2. 只在 L20 内部优化相关指尖距离时，点 FK 可以让指尖靠近，但这没有接触方向、碰撞或真实执行器约束。

因此，问题不是继续寻找一张“完全贴合 L20 的 MANO 表面”，而是需要把人体外观、功能骨架和机器人机构分开表示。

## v15 模型定义

`R_L20` 由两个互补部分组成：

### 1. 自然拟人表面 `S_R`

- 使用 MANO 左手网格；
- 固定一个可辨认的人手形状，例如 v13 的有界 β 候选或 v12 的标准 `beta=0`；
- 固定自然平展参考姿态；
- 不把 L20 CAD 外壳嵌入表面；
- 不要求表面包住 L20，也不把表面顶点直接当作机器人 link。

表面只负责可视化和第一阶段的人体形态中间表示。

### 2. 功能骨架 `K_R`

功能骨架仍使用人手语义：腕部、拇指 CMC/MCP/IP、四指 MCP/PIP/DIP/指尖。它不能直接复制 L20 的机械关节原点，而要保存：

- 人手语义的关节顺序；
- 每根指骨的相对方向；
- 掌部坐标系；
- 指骨长度比例；
- 拇指与各指尖的相对位置；
- 捏合/对指所需的相对距离和方向。

L20 URDF/meshes 用来提供目标机构的可达范围、轴、限位、link 几何和 mimic；它们不直接替换 `K_R` 的人体语义。

## 两阶段接口

```text
操作者 MANO(β_i, θ_i)
        ↓ 阶段一：人体尺寸归一化/形态映射
共享 R_L20 = (S_R, K_R, z_R)
        ↓ 阶段二：机构约束重定向
L20 q：16 个独立坐标 + 5 条 mimic
        ↓ 需要 E_L20 后才可定义
L20 u：执行器命令
```

所有操作者共享同一个 `S_R`、`K_R` 和特征接口；操作者差异只出现在阶段一输入和输出动作状态中。

## R→L20 的目标函数

不再要求所有绝对坐标逐点重合。对每一帧，使用相同的功能特征：

\[
\mathcal{L}(q)=
\lambda_d\mathcal{L}_{direction}+
\lambda_l\mathcal{L}_{length}+
\lambda_p\mathcal{L}_{pair}+
\lambda_w\mathcal{L}_{wrist}+
\lambda_s\mathcal{L}_{smooth}+
\lambda_c\mathcal{L}_{collision}
\]

其中：

- `direction`：对应指骨方向误差；
- `length`：归一化指骨长度误差；
- `pair`：拇食指、拇中指等任务指尖距离/方向误差；
- `wrist`：腕部位置和掌部朝向误差；
- `smooth`：相邻帧 q 变化；
- `collision`：接触、穿透和不可行姿态惩罚。

`q` 通过 L20 URDF 限位和 mimic 展开，优化变量始终是 16 个独立运动学坐标。`u` 在没有完整 `E_L20` 前保持未定义。

## 构建步骤

1. 冻结自然 `S_R`，不再用无界 β/θ 追逐机械点；
2. 从 MANO 标准关节构建 `K_R`，保存人手语义的局部骨架；
3. 从 L20 URDF/meshes 计算对应的功能特征，不把机械原点直接宣称为人体解剖点；
4. 用张开、拇食指捏合、拇中指对指、侧捏等动作，建立 `K_R` 特征和 L20 q 的离线约束优化基线；
5. 同时报告绝对点误差、方向误差、指尖距离、限位违规、mimic 残差和碰撞/接触失败；
6. 如果功能特征可达而表面不重合，保留 R；如果功能特征也不可达，调整 `K_R` 的骨长/参考坐标，而不是把表面继续扭成机械形状。

## v15 验收门槛

以下项目在运行前冻结，当前均为**未运行**：

- [ ] R-only 表面保持可辨认自然手形；
- [ ] 阶段一输出的 R 功能特征在统一坐标/单位下可复现；
- [ ] 张开动作的方向和归一化骨长误差；
- [ ] 拇食指和拇中指对指的指尖距离与方向误差；
- [ ] L20 独立 q 限位违规率；
- [ ] 5 条 mimic 残差；
- [ ] 碰撞/接触约束和不可达样本比例；
- [ ] 不把 task-only 指尖相交当作真实捏合成功。

v14 的全绝对点基线和 task-only 对照保留在 `../v14_R_L20_constraint_baseline/`，作为 v15 的诊断参照，不作为最终方法结果。

## 已运行的第一版基线

第一版实现见同目录的 `feature_baseline/`：使用 v12 的自然 `beta=0` 表面，生成张开、拇食指捏合、拇中指对指三个固定合成动作，并在相对功能特征上优化 L20 的 16 个独立 `q`。当前结果为：张开骨方向 RMSE `12.952°`；拇食指和拇中指选定对的归一化距离误差分别为 `0.0003` 和 `0.0004`；mimic 残差均为 `0`。这是 q 级 smoke baseline，不是接触、碰撞、摄像头或执行器结果。

任务优先权重和完整指标见 `feature_baseline/metrics.json`；失败边界见 `feature_baseline/failure_cases.md`。MuJoCo 离屏渲染位于 `feature_baseline/renders/`，ASCII 场景位于 `experiment/v15_R_L20_feature_baseline_mujoco/`。

为确保显示的是动作后的 R，而不是静态参考表面，另外生成了三个动态 MANO-R OBJ 和对应的 L20 q 场景：`experiment/v15_R_L20_feature_baseline_mujoco/dynamic_renders/`。这些图只用于观察“自然 R 动作 + L20 q 解”是否同步，接触数没有作为成功指标。
