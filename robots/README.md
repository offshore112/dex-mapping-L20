# 机器人模型与驱动资料

当前已读取 L20 左手 URDF 的结构并核查本地网格资源；机器人 FK、仿真与真实控制尚未运行。`_模板/robot_descriptor.example.json` 是候选字段示例，不对应任何真实手，不可直接用于控制。

用户现已提供 L20 左手官方来源与本地目录；在线关节/联动及本地资源核查见 [L20_left/model_notes.md](L20_left/model_notes.md)。来源审计 JSON 不代替可控制的机器人描述。

每个机器人建一个独立目录：

```text
robots/<手型名>/
├── model/              URDF 与原始网格资源
├── descriptor.json     已核查的机构与驱动描述
└── model_notes.md      来源、版本、许可、单位和核查记录
```

描述至少包括：掌部/腕部参考系、几何点及对应关系、每个关节的名称/父子/轴/原点/限位、独立控制量及单位/范围、驱动到关节的关系、必要状态和接触条件、左右手、FK/仿真接口。

URDF 内已知信息可解析；缺少的驱动与肌腱信息要从厂商文档、控制 SDK 或实际识别补齐。缺失时明确标记，不假设每个关节都是独立电机。固定耦合示例与接触依赖欠驱动要分开验证。

首次导入的核查：模型资源齐全；米/弧度约定明确；小幅命令运动符合预期；关节和执行器顺序分别记录；指尖定义与 FK 一致。记录来源 commit 和模型版本。
